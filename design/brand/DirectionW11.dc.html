Nearly square, so it takes an avatar crop with no redraw.

Why
W7 stacked the two words and had to live with a ragged right edge. This forces both lines to the same measure instead, so all four edges are flush and the name becomes a solid block — the frame drawn by the type itself rather than added around it. The proportion lands close to square, which is the shape a profile picture, an app icon and a stamped case badge all want.

Tradeoff
Justifying four letters to the width of six means DATA is held apart by gaps you can drive through, and forced tracking of that size always looks slightly wrong to anyone who sets type. It also loses the hyphen entirely, so it stops matching the domain exactly.
